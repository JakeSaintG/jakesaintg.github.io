## Part of the Pokedex App Project live journaling

Is this one of those rare projects that a developer gets back to? ABSOLUTELY!

However, I had a few things that needed to be done first. While talking with one of my developer friend, I received the wonderful advice to blog about the Pokedex App project…so I needed a blog. I had already written two blogs by this point and should probably put them somewhere.

While I could have used any number of existing platforms, templates, or services, I decided to roll a blog into a new personal landing page. I had been meaning to update my personal page and practice with React but had kind of put it off.

To be honest, I didn’t do anything fancy. I really wanted to not let scope-creep get the better of me… So,I have a section on my new page that loads a markdown file when the desired blog is open. No API, no storage, and I have to make a commit to my personal page every time I upload a new blog. Is it the best solution? No… Does it work for now? Yes!

Anyway, I’m back to having the Pokédex App Project as my main focus! Stay tuned for more!
